# 广东：稳健目标坐标与按预测步长分头

已完成的稳健损失与线性叶验证都仅部分缩小MAE差距，完整记录保留。本阶段依据已运行LEAR的实现差异继续有限研究：LEAR有24个独立h模型，并在训练期中位数/MAD归一化后使用asinh目标；现有LightGBM仍将h混在一起。不是按测试输赢挑选样本，所有原三窗/种子42初筛及对照都保留。

固定两个配置：asinh_shared和asinh_per_h。二者共享同一原三窗、Chronos和完整安全LEAR起报历史/外生曲线/日历，加上已有h对齐本地与价差特征。独立树使用同等原生曲线，但严格剔除所有上游点/c及点衍生价差。c始终只进入训练损失，不进入输入。

历史目标严格取起报前数据；外生曲线沿用既有LEAR基线的同一可用性配置假设，本阶段不额外声称已逐项核验真实发布时间。

目标变换`T(y)=asinh((y-m_train)/s_train)`，s为MAD/0.67448975（退化时1）。主方法训练`T(y)-T(Chronos P50)`残差，输出`T^-1(T(P50)+树修正)`；独立树直接学T(y)。asinh是单调映射，保留P50的中位数含义；原始目标文件与评价单位不变。自定义非对称平方损失定义在**变换后的残差坐标**，梯度b*r_z、Hessian b；不能声称仍是原始价格平方误差。验证早停则通过反变换始终计算原单位RMSE，最终MAE/RMSE也在原单位。

每个头的T仅由其训练样本估计。80/20训练探针另拟合自己的T（只取前80%），净化标签时间交叉，固定300轮；后20%的变换坐标误差估计方向和日块SE软强度≤.5。所有均值/尺度均不取验证或测试。原增益阈值.08按中心尺度除s²转换为新坐标阈值，避免单位改变造成额外强惩罚。为控制分头容量，两个配置统一31叶、最小叶80，其他树参数沿用；这属于明确的目标/训练头结构改动。

比较ordinary/fixed/cas_10/shuffle_10/tree_only五方法。共享头3窗×5=15主拟合；逐h为3窗×24×5=360，共375个主模型、75个训练探针，聚合为30条完整窗口验证记录。默认8个头并行、每个2线程，最多不超过可用CPU核。逐h早停独立，汇总必须先按原行/h回填全部预测再计算指标，不平均各头RMSE，以免改变度量。

CAS与单独树分别以完整三窗验证均值的`max(MAE/54.60651697764482,RMSE/94.56828737273588)`最小选配置，平局RMSE再配置名。仅seed42初筛，若有实质改善才冻结配置补43/44；不能挑最好h、窗口或种子。没有测试数组访问、没有预测裁剪；溢出则报错，不能裁剪成有利值。后续旧测试复评均为开发记录，不重新称独立确认，最终泛化需另留数据。

入口`python -u scripts/pilot_cas_asinh_heads.py`。输出`results/cas_asinh_heads_validation_20261029`，包括不可变源数据/代码校验计划、逐头目标与校准、全部检查点及验证预测、原行聚合的VALIDATION_ALL/SUMMARY、选择记录与完成状态。
