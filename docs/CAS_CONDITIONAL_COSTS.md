# 下一项训练期假设：c是否对应不同方向的剩余偏差

冻结lambda=1的三种子确认完成后：广东c的平均验证RMSE93.8912，打乱93.6881；微弱优势未复现。德卢c平均46.8765，普通47.0274、固定47.0474、打乱47.1152，但种子44反向。均不能证明c稳定胜出，因此暂不进入新测试期。

下一项有限研究只使用训练/验证：保持已冻结的目标h对齐特征、Chronos残差+LightGBM结构以及c仅用于损失。新增假设是同一个h中，不同c样本的剩余误差可能方向不同，单一h方向会相互抵消。用前80%训练起报拟合固定300轮探针，拟合中心及c分位阈值都只取拟合段；在后20%训练留出估计偏差，仍净化多步标签重叠。每个h的c三分位分组预先固定，不搜索组数。

每组误差均值以`rho=n/(n+100)`向该h均值收缩，结合组内误差标准差与按日块SE，将重点侧额外代价限制在[0,0.5]。不足10样本或7日块的组保持中性。正负误差两侧分别得到系数a(c,h)、b(c,h)，取值[1,1.5]；方向来自组内收缩偏差。梯度为coef*r、Hessian为coef。c不作为回归器输入。

这是对原机制的明确扩展：c除了调节强度，也通过训练期条件偏差决定重点侧。不能称为仅换lambda，也不能将所得结论冒充原固定方向公式的证据。新增主要方法conditional_c、同h两侧系数分别均值匹配conditional_mean、在h内共同打乱两侧系数conditional_shuffle。匹配保证候选两侧系数的边际均值一致，不保证每轮实际残差子集有效均值一致。保留普通/固定/原lambda1三个既有对照。

两个市场×三个窗口×三个种子×六方法=108份验证记录，复用既有54份模型指标，新训54份匹配模型；另有6个300轮训练期探针。固定组数、收缩量、强度上限、样本/日块阈值，不按开发测试成绩搜索。这阶段完整保存训练留出残差、c、h与时间（显式ns）及72组诊断，检查c是否含方向性信息。脚本不索引测试数组。若新增方法优于均值/打乱且跨种子稳定，才能支持继续冻结规则并独立评测；若失败，完整报告，不能只挑条件。
