# 真实数据优化与半合成方向性偏移开发实验

实际数据启动检查发现：原特征manifest为无时区上海墙上时间，外部基线manifest为显式+08:00。首版新增对齐检查曾错误地将前者解释为UTC，在任何新树训练前拒绝了六个真实case。修复仅统一解析为原有上海时区；价格、时间值和划分均不编辑。旧plan另存审计副本，所有实验设定保持不变，仅更新代码校验和；已生成的半合成预测按校验和复用。

运行前固定全部18个case：真实广东/德卢各三个窗口，加上广东正负两个方向、每90天0.5或1.0个原训练价格标准差的线性趋势、三个窗口，共12个半合成case。种子42，仅作开发；不得根据测试收益追加、删减或挑选条件。旧测试期已经被检查过，不能重新称为全新独立测试。有效条件需冻结后补多种子及未用于选择的新时期。

半合成目标为`y'(t)=y(t)+sign*strength*std_original_train*max(0,(t-train_start)/90days)`。尺度仅取对应窗口原训练段，正负方向都报告。原始CSV不编辑，所有变换另存且保存校验和。只干预价格目标，外生变量不变；这不是完整电力系统干预模型，更不能声称是真实广东性能。每个case重新生成因果Chronos预测、历史价格特征并训练LEAR小时起报适配版/RNN，不能把原预测直接拿去评价新目标。

每个case有18个方法：独立Chronos、独立丰富特征树、原Chronos+树普通损失基线、原特征残差表示的普通/固定/真实c/均值c/打乱c五种损失、丰富特征残差表示同五种损失及训练内方向门控的温和固定/真实c/打乱c三种损失、LEAR适配版和真循环RNN。c始终不进入输入。丰富特征将既有LEAR的96维滞后价格日曲线、可用外生曲线和日历项按原起报编号对齐到每个h，保留多步过滤产生的缺失目标掩码，不改样本顺序或划分。

强非对称重点侧系数为`2(2-c)`，固定/均值/打乱对照同方向；非重点侧为1。温和门控仅利用训练内前80%拟合的固定300轮残差探针，在后20%按h计算偏差；拟合标签时间必须早于留出首次起报。探针中心也仅使用拟合段。偏差绝对值≤拟合价格标准差5%时该h中性，否则取偏差符号。门控重点侧为`1+0.25*w`，`w=(1+0.3*(1-c))/mean_train(1+0.3*(1-c))`；固定与打乱做同强度控制。它仍是c调节非对称损失，不是c作为输入。

LightGBM参数与前一轮一致，2000轮上限、100轮早停，普通验证RMSE选轮；所有目标按训练均值中心化，统一零初始化。原真实数据基线和36份兼容模型复用，不重训LEAR/RNN；其余234份树模型及12份LEAR、12份RNN新训练（不含18份300轮探针）。所有候选完整保存。三个CAS变体用验证RMSE选择，selection.json先写入后才读取测试数组。选择不会参考LEAR/RNN测试成绩，也不会在失败后按测试改参数重试。

```bash
conda activate efp
cd ~/CAS/CAS-EFP-transfer
python -u scripts/run_cas_directional_study.py
```

输出`results/cas_directional_study_20261029`，包括不可变`plan.json`、每case独立日志、selection.json、训练期校准记录、全部模型、预测、ALL_RUNS.csv、SUMMARY.csv和completion.json。18case×18方法=324条单种子评价记录。半合成方向/强度各自汇总，不能与真实市场混合平均。第一次完整运行即结束；不以“赢过全部对照”作为停止条件。
