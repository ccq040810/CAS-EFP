# 第二阶段：预测步长对齐与软偏差强度，仅训练/验证

第一阶段训练期诊断显示，原广东门控的24个h全部处于中性分支，固定/c/打乱三个模型实际上相同，不能检验c作用。同时，已有丰富输入提供24小时完整日曲线，池化树需要先利用h才能选择对应历史列。第二阶段将这两个可检查的机制问题作为假设，预先固定36组开发拟合，不以测试收益追加候选。

保持Chronos+LightGBM+c仅入非对称损失。保留原局部特征，增加原起报历史中与目标h对应的D-1/2/3/7价格、这些价格与Chronos点预测的价差、跨日价格变化，以及目标h的已知外生变量及滞后曲线。使用上一阶段已核验的LEAR输入按原h编号抽取，保持所有样本与划分。c列从模型输入删除。相对价格特征用于降低价格水平变化对树分裂的影响，并不保证一定有效。

只用训练内前80%起报拟合固定300轮残差探针，拟合标签时间须早于留出首次起报，中心也只取拟合段。后20%按h计算剩余误差**均值**及标准差，用起报日期的日均误差估算块间标准误SE；这只是收缩启发式，不宣称统计覆盖保证。方向为均值符号，重点侧强度`s_h=min(0.5, |bias|/residual_sd * |bias|/(|bias|+2SE))`，不足7个日块则中性。相比上一阶段硬阈值，软收缩允许小而可信的偏差产生有限代价，也使方向估计与平方误差目标一致。

普通损失；固定`1+s_h`；c权重`1+s_h*w`，lambda预先设0.3/1.0；相应两组h内打乱对照，共6候选。`w=1+lambda*(1-c)`在每个h内归一化为均值1，打乱也仅在h内进行，故固定与c/打乱匹配各h候选平均强度。另一侧代价为1，梯度为b*r、Hessian为b，全部权重有限且为正。24个h的方向和强度只用训练期留出估计。所有候选使用相同特征、初始化、树参数与普通验证RMSE早停。

广东/德卢各三窗、种子42，输出`results/cas_horizon_aligned_validation_20261029`。脚本只索引X_train/y_train/X_valid/y_valid，不索引测试数组，不计算新测试分数。第一阶段已见真实测试期只作开发参考。先完整报告36组验证与训练诊断，再决定是否冻结候选开展多种子/新时期确认，不能把验证挑选后的分数作为独立测试证据。
