# 冻结配置的三种子验证确认

36组第二阶段候选完成后，lambda=1的c方案在两市场平均验证RMSE均优于普通/固定/打乱对照，但广东对打乱仅约0.017%的优势很小。依照事先“训练/验证支持再多种子”的规则，冻结lambda=1、同一特征和训练期校准规则进行确认；不根据测试表现追加参数。

两个市场三个窗口，种子42/43/44，每个比较普通残差L2、固定非对称、c(lambda=1)、h内打乱(lambda=1)，以及同目标h对齐特征的单独树和普通绝对价格融合。共108份验证记录，复用种子42四个残差候选共24份模型，新训练84份。lambda=.3候选完整保留在上一阶段，不在确认阶段继续搜寻。

所有种子共享已保存的种子42训练内300轮探针方向与软强度，避免将校准改变混入随机种子敏感性。单独树明确剔除上游点/c列及所有依赖上游点的价差，仍拥有同h历史价格/曲线和当地特征。所有模型均统一训练均值中心化/零初始化、2000轮上限、100轮普通验证RMSE早停。候选全部报告，不只报告最好的随机种子。

`scripts/confirm_cas_horizon_aligned.py`仅索引训练与验证数组，不读取测试或生成测试预测。输出`results/cas_horizon_aligned_confirmation_20261029`中的VALIDATION_ALL.csv、PER_SEED.csv、VALIDATION_SUMMARY.csv、plan.json与completion.json。均值与标准差先每种子平均三个窗口，再跨种子计算；不把重叠窗口当独立样本做显著性结论。若优势不能在种子间稳定复现，应如实判断c证据不足。若支持，再冻结统一配置，用此前未用于有效方法选择与指标比较的新时间段独立检验；旧测试不重新命名为新测试。

```bash
python -u scripts/confirm_cas_horizon_aligned.py
```
