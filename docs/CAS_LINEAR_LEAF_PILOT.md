# 广东：线性叶节点LightGBM验证开发

稳健基损失使广东验证MAE约57.23降至56.82，但仍落后LEAR54.61，尚未解决问题。因此不靠增加测试筛选，新增一项有结构依据的训练/验证研究：保留Chronos+LightGBM+c仅入损失，将LightGBM叶节点从常数改为局部线性函数。它是下游内部结构的明确改动，不应称为只调整损失。

官方参数说明：`linear_tree=true`进行分段线性提升，每叶使用分支中的数值变量，第一棵树仍为常数叶；建议特征均值/标准差接近。源码用梯度g、Hessian H及linear_lambda构造局部正则Newton回归，因此自定义c加权的两阶信息会进入叶系数，不能假定权重相互抵消。

- 参数：https://lightgbm.readthedocs.io/en/latest/Parameters.html#linear_tree
- 官方实现：https://github.com/lightgbm-org/LightGBM/blob/main/src/treelearner/linear_tree_learner.cpp

研究假设是局部线性叶能更有效学习安全历史价格/日前价格等连续关系及残差修正，比常数叶更接近LEAR的线性拟合能力，同时保留树分区。只是待检验假设，不预设必胜。数据、三个窗口、Chronos及h对齐特征不变，c不进入输入。直接比较同一新结构的普通/固定/c/打乱损失，另训同结构独立树；其输入严格删除上游点/c与点衍生价差，不能用弱常数叶基线冒充新结构的单独树。

固定三个配置：平方损失+linear_lambda1、平方损失+linear_lambda100、混合稳健gamma0.5+linear_lambda1。其余树参数沿用先前版本。只做种子42初筛：3配置×5方法×3窗口=45拟合。根据完整三窗验证双指标选定配置后，若有实质收益才冻结补43/44，不选择最好种子。

预处理用训练期中位数填充，按训练均值/标准差归一化，并显式追加缺失标志，避免将缺失悄悄当观测0。探针预处理也仅用前80%拟合段。300轮线性L2训练内探针，目标标签时间净化；后20%估计方向、软强度及delta，不使用验证/测试标签。稳健独立树的delta由独立树自己的训练内探针估计。各主要方法同配置、预处理、初始化、早停，保留全部候选。

CAS和独立树分别按`max(validation_MAE/54.60651697764482, validation_RMSE/94.56828737273588)`最小选配置，平局按RMSE再配置名。这两个分母是既有四外部对照的验证最优值（均LEAR）。所选CAS与所选独立树都确认后，再决定是否继续开发复评；不按旧测试成绩选择本阶段配置。最终泛化仍需另留确认数据，旧测试不可再次包装为新测试。

本地和Linux必须通过真实LightGBM线性叶/自定义目标一致性、c权重产生实际变化、序列化和训练期预处理测试，才启动。入口`python -u scripts/pilot_cas_linear_leaves.py`，输出`results/cas_linear_leaf_validation_20261029`，仅训练/验证，无测试指标。
