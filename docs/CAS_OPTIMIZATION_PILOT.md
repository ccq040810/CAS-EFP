# 置信度加权LightGBM：训练/验证诊断

核心保留冻结Chronos-2、LightGBM、c进入损失。只用修复后的因果v2特征，不使用旧故障回放。新脚本不索引或物化X_test/y_test；已看过的旧测试成绩不用于候选选择。不会覆盖或重新生成LEAR/RNN结果。

首轮固定种子42，两个市场三个窗口，比较绝对价格回归和Chronos残差回归：后者输出point+LightGBM修正，允许保留上游跨价格水平外推。对每种表示比较8个预先固定候选，共96次完整训练和12次训练内诊断探针。下游树参数一致，普通验证RMSE早停。

训练内前80%起报用于固定300轮探针；仅训练标签时间早于后20%首个起报点的样本可拟合探针，以免多步重叠造成标签泄漏。后20%用于计算下游留出残差中位数、c与绝对误差的Spearman相关。接近零的偏差（小于训练价格标准差的2%）进入中性分支，不强行惩罚某一方向。这里是训练期留出诊断，不声称置信度已完成概率校准或有覆盖保证。

候选：普通L2；温和固定非对称alpha=1.25；归一化置信度调节lambda=.1/.3；同均值固定和打乱权重对照；双侧较高置信样本加权；原始alpha=2、lambda=1、基础模型残差方向。温和方向系数为1+(alpha−1)w，w=(1+lambda(1−c))/训练均值，另一侧1。其平均强度较原始2(2−c)弱；matched_mean与fixed_mild在该归一化定义下数学等价，是明确的强度核验，不算独立证据。

只有在同一表示下加权稳定优于ordinary和fixed_mild，且不能被均值/打乱对照解释时，才支持继续发展置信度分配机制。若只有残差表示提升，应归因于表示改变，不能归功于c。reliability_symmetric是诊断对照，不冒称非对称机制。最终需在未用于方法选择的时间段验证，不能承诺最优。
