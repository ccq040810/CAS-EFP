# 双指标目标：稳健基损失与c非对称代价

用户最终标准为完整c方案在两市场×MAE/RMSE四项中至少三项第一，余项最多第二。原三窗固定模型测试为德卢两项第一、广东两项第二，仍不达标。当前开发只集中广东：原验证中MAE57.2306高于LEAR54.6065，平方损失的尾部强调是否影响平均误差值得检查。恢复此前已准备、测试过但未运行的稳健损失草稿，保留所有既有结果；本阶段只使用训练/验证，德卢方案保持原状。

本阶段保持Chronos+LightGBM残差结构、目标h对齐安全特征、c只用于非对称损失。研究平方损失对大误差的强调是否造成平均绝对误差偏高，在不改数据/样本/划分的情况下加入稳健基损失：

`phi(r)=gamma*r²/2 + (1-gamma)*delta_h²*(sqrt(1+(r/delta_h)²)-1)`。

gamma预先固定1、0.5、0.25；gamma=1为既有平方损失，另外两值作有限开发，不继续搜索。delta_h由训练期留出残差MAD×1.4826估计，下限为max(0.05×残差std,0.001)。训练期留出来自此前80/20净化时间探针；不含验证/测试标签。对每种gamma，以留出误差的稳健梯度score均值估计偏差方向，继续使用按日块SE软收缩重点侧强度≤.5，避免用平方误差偏差方向直接冒充稳健方向。

对phi乘固定/真实c/打乱c非对称系数，另有普通phi损失。c仍lambda=1且h内归一化；固定、c和打乱同h候选系数均值匹配。phi梯度为`gamma*r+(1-gamma)*r/sqrt(1+(r/delta)²)`，Hessian为`gamma+(1-gamma)/(1+(r/delta)²)^(3/2)`，有正下界gamma，避免纯稳健尾部零曲率。自定义梯度和Hessian都乘同一代价；不以错误Hessian伪装优化。伪Huber引入是基损失的明确扩展，不能声称仍是原平方损失公式。
